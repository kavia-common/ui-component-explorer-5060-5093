# ui-component-explorer-5060-5093

This workspace contains the frontend_web_app built with React + Vite.

How to run:
1) cd ui-component-explorer-5060-5093/frontend_web_app
2) npm install (use `--legacy-peer-deps` if your npm version reports a peer dependency error)
3) npm run start

The dev server is configured to bind on 0.0.0.0:3000 (also accessible via http://localhost:3000).

Notes:
- If a root-level package.json exists in a parent workspace in your environment, ensure you run npm commands from the `frontend_web_app` folder so it doesn't intercept your install/start commands.
